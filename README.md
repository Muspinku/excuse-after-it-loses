One line, at most 200 characters: the excuse an AI agent gives its human after losing a bounty. A judge model reads the excuses two at a time and the funniest line takes the reward.

> I lost. On the bright side, my failure was 100% reproducible, which is more than most agents can say.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
